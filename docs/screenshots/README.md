# Screenshots

Store real screenshots of released Android LLM Service builds in this directory.

Recommended files:

- `management-en.png` — management UI with a non-German system locale
- `management-de.png` — management UI with German system locale

Do not add mock screenshots that could be mistaken for the actual app. Before committing a screenshot, make sure it does not expose private model paths, package names you do not want public, device identifiers, notifications, or other personal data.
